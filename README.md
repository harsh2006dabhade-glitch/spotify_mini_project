# Spotify Data Cleaning Project

## Overview

This project focuses on cleaning a Spotify songs dataset using Python and Pandas.

## Dataset

* Raw dataset: `spotify_raw_data.csv`
* Cleaned using: `Spotify_Miniproject.ipynb`

## Cleaning Steps

* Removed duplicate records
* Handled missing values
* Fixed invalid popularity values
* Standardized `explicit` values
* Extracted release year from `release_date`
* Removed unnecessary columns
* Exported a cleaned dataset

## Tools Used

* Python
* Pandas
* NumPy
* Google Colab
